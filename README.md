# B站一键下载

面向 Windows 的轻量下载启动工具。复制 B站视频链接，双击运行，自动下载并合并成 MP4。首次运行自动准备 yt-dlp 和 FFmpeg，之后不需要输入命令。

## 使用方法

1. 将分享包 ZIP **全部解压**到一个固定、可写的文件夹。
2. 在 B站复制视频链接。
3. 双击 **`一键下载.cmd`**。

首次使用需要联网下载所需程序，其中 FFmpeg ZIP 约 100 MB。进度窗口会显示当前阶段。以后直接下载视频；下载完成后自动打开文件夹。

视频保存在工具旁边的 **`下载的视频`** 文件夹。可以给 `一键下载.cmd` 创建桌面快捷方式，视频仍保存在工具原目录下。

如果剪贴板没有 B站链接，会弹出粘贴输入框。支持 `b23.tv` 短链接，以及包含链接的分享文字。普通视频链接会清理跟踪参数，并保留分 P 参数 `p`。

## 环境

- Windows 10 / 11，64 位；推荐 x64 电脑。
- 使用 Windows 自带的 PowerShell 5.1；不需要安装 Python 或使用管理员权限。
- 首次联网准备需要能访问 GitHub 和 gyan.dev。准备文件时使用系统网络设置。
- 视频请求默认直连 B站，曾验证可解决本机系统代理导致的 HTTP 412。不同网络环境下可能需要调整。

## 三个入口

| 文件 | 用途 |
| --- | --- |
| `一键下载.cmd` | 读取复制的链接并开始下载 |
| `设置.cmd` | 切换视频连接方式：直连 / 使用系统代理 |
| `更新下载器.cmd` | 从上游获取最新 yt-dlp 和 FFmpeg |

准备程序时会核对上游提供的 SHA-256；未通过校验的文件不会安装。启动器仅为本次 PowerShell 进程指定执行策略，不修改系统执行策略。

## 手动准备

如果首次自动准备失败，可以把下面三个文件放在 `一键下载.cmd` 同一个文件夹，然后再次运行：

```text
yt-dlp.exe
ffmpeg.exe
ffprobe.exe
```

- [yt-dlp 官方 Windows 下载](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe)
- [FFmpeg Windows ZIP 下载](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip)：解压后，从 `bin` 取出 `ffmpeg.exe`、`ffprobe.exe`。

如果使用手动提供的程序，更新入口会准备新的内置版本；请移走根目录的旧 EXE，普通下载才会使用 `.tools` 内的新版本。

## 常见问题

**HTTP 412 / 403：** 网站拒绝了请求，原因可能涉及线路、网站风控或兼容变化。默认直连；可以打开 `设置.cmd` 切换线路。更新下载器后仍失败时，先确认同一视频可在浏览器播放，再保留具体报错以便排查。

**画质：** 使用当前未登录状态下可获取的最佳画质，优先选择 H.264 / AAC 以便普通播放器打开。不同视频可能需要登录或会员才能获取某些画质。本工具没有自动读取浏览器账号或登录 Cookie 的功能。

**多 P / 合集：** 默认不主动下载整个合集，视频网址有 `?p=2` 等参数时保留该参数。网站提取器的行为可能随版本变化。

**窗口立即关闭：** 解压完整文件夹，保持三个 CMD、`start.ps1` 和 `core.ps1` 在一起。组织管理的电脑可能限制脚本运行。

**百度网盘打开 MP4：** 右键视频 → 打开方式 → 选择其他应用 → 媒体播放器 → 始终。
